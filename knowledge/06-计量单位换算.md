# 计量单位换算（pnl / set / pcs）

## pnl、set、pcs 的层级关系

在 PCB（印刷电路板）生产投料场景中，pnl、set、pcs 是逐级汇总的三个计量单位，由大到小的关系如下：

- **pnl**：由多个 set 组成的「板」或「批次」。每 pnl 包含固定数量的 set，例如 1 pnl = 3 set。
- **set**：由多个 pcs 组成的「套」。每套包含固定数量的 pcs，例如 1 set = 2 pcs。
- **pcs**：单个 PCB 板的计量单位，是最小的基础单位。

三者关系可概括为：**pnl ＞ set ＞ pcs**，pcs 为基础单位。

## 换算方法与示例

换算方向：

- 由大到小：pcs 数量 = pnl 数量 × 每 pnl 的 set 数 × 每 set 的 pcs 数
- 由小到大：pnl 数量 = pcs 数量 ÷ 每 set 的 pcs 数 ÷ 每 pnl 的 set 数

以 1 pnl = 3 set、1 set = 2 pcs 为例：

| pnl | set | pcs |
|---|---|---|
| 1 | 3 | 6 |
| 5 | 15 | 30 |
| 10 | 30 | 60 |

⚠️ 重要提示：1 pnl 含多少 set、1 set 含多少 pcs 由具体产品的**拼版方式**决定。上文的 3 与 2 仅为原文举例数值，**不是通用换算系数**，实际换算必须以该料号的拼版参数为准。
