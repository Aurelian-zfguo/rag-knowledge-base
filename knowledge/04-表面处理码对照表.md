# 表面处理码对照表

## 表面处理码完整对照

表面处理码是物料编码的**第 10 位**，用单个大写字母表示 PCB 的表面处理工艺。共 13 种取值：

| 代码 | 表面处理工艺 |
|---|---|
| L | 无铅喷锡 |
| H | 有铅喷锡 |
| F | 电镀镍金 |
| T | 沉锡 |
| N | 光铜板 |
| P | 镍钯金 |
| X | 沉镍金 + 抗氧化 |
| J | 无铅日秀锡 |
| C | 沉镍金 |
| W | 电金喷有铅锡 |
| E | OSP、抗氧化 |
| S | 沉银 |
| M | 无铅银锡 |

## 表面处理码速查（按工艺归类）

- **喷锡类**：L 无铅喷锡、H 有铅喷锡、W 电金喷有铅锡
- **镍金类**：C 沉镍金、F 电镀镍金、P 镍钯金、X 沉镍金 + 抗氧化
- **沉积类**：T 沉锡、S 沉银
- **抗氧化类**：E OSP、抗氧化
- **银锡类**：M 无铅银锡、J 无铅日秀锡
- **无处理**：N 光铜板

在物料编码 `100000008H0899A` 中，第 10 位为 `H`，即该板件采用有铅喷锡工艺。
