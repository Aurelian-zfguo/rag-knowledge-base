# 工单编码规则

## 工单编码的组成结构（20 位）

生产工单编码固定为 20 位，按 **1-2-9-2-3-3** 分为六段：

| 段位 | 位数 | 字段 | 说明 |
|---|---|---|---|
| 第 1 位 | 1 | 工单类型 | 见「工单类型码对照」一节 |
| 第 2–3 位 | 2 | 投单次数 | |
| 第 4–12 位 | 9 | 销售订单号 | |
| 第 13–14 位 | 2 | 销售订单行号 | |
| 第 15–17 位 | 3 | 流水号 | |
| 第 18–20 位 | 3 | 特征号 | 区分成品与半成品 |

示例拆解 `10111080016001001000`：

- 工单类型 = `1`（正常工单）
- 投单次数 = `01`
- 销售订单号 = `110800160`
- 销售订单行号 = `01`
- 流水号 = `001`
- 特征号 = `000`（成品）

## 工单类型码对照

工单编码第 1 位标识工单类型，分为标准订单与非标准订单两大类。

| 类型码 | 工单类型 | 归类 | 说明 |
|---|---|---|---|
| 1 | 正常工单 | 标准订单 | SO 销售订单（Sales Order）正常转出的成品或半成品工单 |
| 2 | 补投工单 | 标准订单 | 因报废产生的补投，分补料与补芯料 |
| 3 | 退库返修 | 非标准订单 | 成品退库返修的生产业务 |
| 4 | 转厂工单 | 非标准订单 | 受托方加工的内协生产业务 |
| 5 | 签废返修 | 非标准订单 | 品质签废后重新返修的生产业务 |
| 6 | 盘盈工单 | 非标准订单 | 在线盘点盘盈的物料生产业务 |
| A | 研发工单 | — | 示例 `A0112091241701001000` |

## 成品工单与半成品工单的区别

成品与半成品的区别在于**特征号（编码最后三位）**：

- 特征号 `000` → 成品工单，示例 `10111080016001001000`
- 特征号 `101` / `102` / `103` → 半成品工单，末位数字表示层次结构：
  - `10111080016001001101`
  - `10111080016001001102`
  - `10111080016001001103`

## 补投工单：补料与补芯料

补投工单的类型码为 `2`，按报废发生的环节分为两种：

| 名称 | 产生原因 | 特征号 | 编码示例 |
|---|---|---|---|
| 补料 | 由**成品**报废产生的补投工单 | `000` | `20111080016001000000` |
| 补芯料 | 由**半成品**报废产生的补投工单 | `101` | `20111080016001000101` |

补投行为受管控，具体红线见《补投管控措施》。
